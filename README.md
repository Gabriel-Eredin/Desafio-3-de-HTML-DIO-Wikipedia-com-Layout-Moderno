# Enciclopédia Livre — RPGs de Mesa

Projeto desenvolvido como parte do **Desafio 3 do curso de HTML da [DIO.me](https://www.dio.me/)**, com o objetivo de criar uma página inspirada na Wikipédia, utilizando um layout moderno e aplicando conceitos de HTML semântico, estruturação de conteúdo e acessibilidade.

## 📖 Sobre o Projeto

A Enciclopédia Livre é um projeto fictício de enciclopédia dedicada ao universo dos RPGs de mesa. A página apresenta um artigo sobre **Cyberpunk 2020**, abordando sua história, edições, ambientação e adaptações para outras mídias.

O layout foi desenvolvido para organizar o conteúdo de forma clara, com navegação lateral entre categorias, índice de seções, imagens com legendas, conteúdo multimídia e uma área de fontes e referências.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** estruturação semântica do conteúdo, navegação, imagens, tabelas e elementos multimídia.
- **CSS3:** estilização da página, organização do layout e apresentação visual.

## ♿ Semântica e Acessibilidade

Durante o desenvolvimento, foram aplicados conceitos de HTML semântico e acessibilidade, incluindo:

- Utilização de elementos semânticos como `header`, `main`, `nav`, `article`, `section` e `footer`.
- Hierarquia de títulos para organizar o conteúdo.
- Textos alternativos em imagens por meio do atributo `alt`.
- Uso de links e âncoras para facilitar a navegação entre as seções do artigo.
- Organização visual do conteúdo para melhorar a leitura e a compreensão da página.

## 🔗 Sobre os Links

Alguns links são apenas ilustrativos e ainda não possuem páginas de destino. Eles representam como seria a navegação na versão completa da Enciclopédia Livre, na qual cada categoria ou artigo poderia levar a uma página específica.

Os links internos que apontam para seções do artigo estão disponíveis para facilitar a navegação pelo conteúdo.

## 🎯 Objetivo do Desafio

Praticar os fundamentos do HTML5 por meio da criação de uma página inspirada na Wikipédia, explorando a estruturação semântica, a organização de conteúdo, a acessibilidade e a construção de um layout moderno.
